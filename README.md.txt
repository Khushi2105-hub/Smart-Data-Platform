# 💜 Smart Data Platform

An AI-powered data analytics system that automates data cleaning, visualization, and insights.

## 🚀 Features

- 📂 Multi Dataset Upload
- 🧹 Smart Data Cleaning
- 📊 AI-Based Visualization
- 🤖 AI Insights Engine
- 💬 Chat with Dataset
- ⚡ One-Click Dashboard Generator

## 🛠 Tech Stack

- Python
- Streamlit
- Pandas
- Plotly
